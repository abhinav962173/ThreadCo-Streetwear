## About ThreadCo

ThreadCo is a streetwear brand concept brought to life as a frontend e-commerce experience. The idea behind it is simple: clothing that carries the discipline of code and the attitude of the street.

The site is designed to feel like a real drop page. It has confident typography, open space, and nothing standing between the customer and the product.

> *Less noise. More product.*

## Key Features

- Four dedicated pages covering the core storefront flow
- Product-focused collection and detail layouts
- Bold, brand-led typography
- Consistent navigation across every page
- Organised styling with `style.css` and `style2.css`
- Zero dependencies, pure HTML and CSS
- Deployed on GitHub Pages

---

## Design Philosophy

| Principle | What it means here |
|-----------|--------------------|
| **Bold typography** | Type does the talking. Headlines are loud and confident, the way a streetwear label speaks. |
| **Minimal layout** | Clean structure and open space keep attention on the clothes, not the clutter. |
| **Streetwear aesthetic** | Understated, urban, direct. The look takes cues from drop culture rather than traditional retail. |
| **Product-focused UI** | Every page is built around the product. Imagery and pricing come first. |
| **Modern navigation** | A simple, consistent structure that makes moving between pages effortless. |

## Run Locally

```bash
git clone https://github.com/abhinav962173/ThreadCo-Streetwear.git
cd ThreadCo-Streetwear
```

Then pick one:

- Open `index.html` directly in your browser, or
- Use the **Live Server** extension in VS Code and click **Go Live**.
